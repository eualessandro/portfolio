Gerenciamento operacional

Operação de setores e equipes com tarefas aprovadas e registro de tudo.

O SIGEO organiza tarefas, equipes, ponto e materiais em um só sistema, com trilha de auditoria e API para integrar com outros sistemas. Desenvolvido pela Advances.

O problema

Operações espalhadas em planilhas, mensagens e papéis

Sem um lugar único, ninguém sabe o que foi feito, quem fez e quem aprovou.

Sem o SIGEO

  • Tarefas combinadas por mensagem, sem responsável definido
  • Ponto e presença conferidos à mão
  • Estoque de materiais controlado em planilha
  • Ninguém sabe quem alterou um registro

Com o SIGEO

  • Tarefa com início, conclusão, aprovação e reabertura
  • Registro de ponto com localização e QR code
  • Movimentação de materiais registrada
  • Trilha de auditoria de cada ação
Funcionalidades

O que o sistema faz

Lista das funções disponíveis na API e no painel web.

T

Tarefas com fluxo de aprovação

Cada tarefa passa por etapas definidas.

  • Iniciar e concluir
  • Aprovar ou reprovar
  • Reabrir quando necessário
P

Ponto com localização

Registro de entrada e saída com controle de local.

  • Check-in e check-out com GPS
  • Raio de 100 m por padrão, com justificativa fora dele
  • Confirmação por QR code e selfie opcional
L

Locais e áreas

Estrutura do que é operado.

  • Cadastro de locais e áreas
  • Área com QR code para conclusão de tarefa
M

Materiais e estoque

Controle do que é usado e onde.

  • Cadastro de materiais
  • Movimentações de entrada e saída
  • Materiais vinculados a tarefas
U

Usuários e perfis

Acesso por conta, com perfis de administrador, supervisor e funcionário.

  • Cadastro e edição de usuários
  • Foto de perfil
A

Auditoria e relatórios

Registro de ações e indicadores.

  • Trilha de auditoria pela API
  • Relatórios de indicadores pela API
Integrações

API para outros sistemas

Acesso por token de sessão ou por chave de API, com documentação para desenvolvedores.

Autenticação

Token JWT para sessões de usuário e chave de API para integrações.

Documentação

Referência da API publicada no próprio sistema, em formato Swagger.
