Auditoria de favoritos, arquivos duplicados e chaves de API expostas.

O que o sistema faz

Funções do aplicativo para Windows e da extensão do Chrome.

Favoritos do Chrome

Auditoria dos favoritos do navegador.

  • Identificação de duplicados
  • Organização automática
  • Escolha do perfil do Chrome

Arquivos duplicados

Varredura de uma pasta, por conteúdo.

  • Comparação por SHA-256
  • Lista de grupos duplicados
  • Nenhum arquivo é apagado automaticamente

Chaves de API expostas

Alerta em páginas abertas no navegador.

  • Padrões de chaves de OpenAI e Anthropic
  • Verificação na página aberta

Aplicativo para Windows

Executável portátil.

  • Versão portátil para Windows
  • Não exige instalação
